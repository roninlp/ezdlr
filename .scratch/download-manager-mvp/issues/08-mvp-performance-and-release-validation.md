# 08 — MVP Performance and Release Validation

**What to build:** The complete MVP is validated against its responsiveness and resource goals through representative end-to-end workflows on Arch Linux and Windows when supported.

**Blocked by:** 05 — Clipboard Batch Review and Intake; 06 — Arch Linux Distribution; 07 — Windows Distribution

**Status:** ready-for-agent

- [ ] Launch-to-usable-UI timing and idle CPU and memory behavior are measured with lightweight app and OS tools.
- [ ] Clipboard batch review and three-concurrent-download workflows are validated, including pause, resume, restart, and recovery.
- [ ] Queue controls and status remain responsive while three downloads are active.
- [ ] Arch Linux results are recorded on a modest everyday laptop, with the same checks repeated on Windows when that environment is available.
- [ ] Validation uses broad MVP criteria rather than hardware-specific hard budgets and records any release-blocking regressions.
